# Interpreters reachable from the CG Groovy box

Verified 2026-10-22, test 1 of `telephone-numbers-codesize`, `new ProcessBuilder('<interp>','-e','<core>').inheritIO().start()` (generated by `agent/wrap/groovy/`):

- `python3 -c`, `php -r` (/bin/php 7.3.9, code without `<?` tag): on PATH, test passes
- ruby 3.1.2 only at `/usr/local/bin/ruby` (off PATH): `'ruby'` = not found, `'/usr/local/bin/ruby'` passes
- no `node`/`nodejs` (PATH, /usr/bin, /usr/local/bin)
- perl, bash, lua: known before (perl-wrapper-processbuilder.md, music-scores lua 294)

Local launcher has neither php nor /usr/local/bin/ruby: those wrappers fail locally while CG accepts them.

Literal choice for the core (local groovy 3.0.8):
- single quotes: escape `\` `'`, newline as `\n`; `$` free
- slashy `/.../`: only `/` needs `\/`, raw `\` and newlines, but `$` + letter/`_`/`{` interpolates and `\$` does NOT escape it; `\uXXXX` still decoded; `$1`, `$|`, `$ `, `$` before the closing `/` stay literal
