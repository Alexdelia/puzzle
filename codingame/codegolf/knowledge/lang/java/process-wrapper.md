Verified 2026-10-22 (CG temperature-code-golf Java tests 1/3, the-descent-codesize test 2 game 910946478; journal `agent/state/journal/wrap.-.java.1792694203234589341.md`). Generated by `agent/wrap/java/`.

- form: `interface Solution{static void main(String[]a)throws Exception{new ProcessBuilder("perl","-e","...").inheritIO().start();}}` = core + escapes + 120 (perl -e). `throws Exception` is required (`start()` throws IOException)
- io: no `.waitFor()` needed, the orphan child still answers (6 cores CG success). Interactive: main type `Player` and `.waitFor()` (+10, `knowledge/lang/_shared/orphan-child-kill.md`)
- CG Java box = Kotlin box: `/usr/bin/python3`, `/usr/bin/perl` 5.34, `/bin/php` 7.3.9, `/bin/lua` 5.4.4, `/bin/bash`, `sh`; ruby 3.1.2 only at `/usr/local/bin/ruby` (off PATH); no node/nodejs
- literal choice: `"..."` escapes `\` `"` newline (2 B each); text block `"""<LF>...."""` costs +5 but keeps `"` and newlines raw. In a text block `\` still needs `\\`, a `"` followed by `""` or ending the core needs `\"`, trailing space/tab of a line is stripped (write the last one as `\s`/`\t`), and common leading indentation is stripped (unsafe when every line is indented)
- `\u` in a core: doubling the backslash (`\\u`) stops Java's unicode-escape pre-pass, in both literal kinds (checked with javac 21)
