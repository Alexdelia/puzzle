# Best kept per language

Probe 2026-10-19, `temperature-code-golf` Python3: row at 70, submitted a 71-byte variant, row stayed 70 at 100%.

- CG keeps the best submission per language: a longer or failing submit never lowers a row
- consequence: a longer submission can't be confirmed through the leaderboard (row unchanged), only a shorter one or the first one in a language
- `/progress` shows the user's best row over all languages, not the last submission: useless to judge one submit
